# Kravings - African Recipe Sharing Platform

Live Demo: https://kravings-theta.vercel.app

Kravings is a web platform for discovering and sharing authentic African recipes. Built from scratch with Next.js.

### Tech Stack
- Next.js, React (JSX), TypeScript, Tailwind CSS
- File-based routing, reusable components, responsive design
- Deployed on Vercel

### Features
- Browse authentic African recipes
- Share your own recipes with ingredients and steps
- Responsive, mobile-first UI with Tailwind CSS
- Fast navigation with Next.js App Router

### How to Run
```bash
npm install
npm run dev
